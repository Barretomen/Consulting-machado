# Machados Consulting

Site institucional para um serviço de contabilidade e fiscalidade em Portugal.

O projeto inclui uma página de apresentação e um formulário por etapas para recolha de informação do IRS 2026. É um site estático feito com HTML, CSS e JavaScript; o envio do formulário usa Web3Forms.

Para testar, abra `index.html` no navegador.
